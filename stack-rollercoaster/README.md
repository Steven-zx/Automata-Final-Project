# Stack Coaster 🎢

Interactive stack visualization styled as an amusement park ride.

## Run
Open `index.html` in a browser or use Live Server in VS Code.

## Controls
- **A** or click "Add Passenger (a)" — push (only when empty)
- **B** or click "Remove Passenger (b)" — pop

## Features
- Colorful coaster cars stack vertically
- Animated push/pop with sound effects
- Entry gate, central tower, exit ramp layout
- Capacity meter & status display
- Keyboard shortcuts
